\begin{abstract}

This article describes a ``light-weight'' approach to write embedded
Ada applications on the Zephyr RTOS environment. Zephyr is an increasingly
popular real-time operating system that supports a wide range of microcontrollers
and boards and it is easily extensible to support custom SoCs and boards. To write
an Ada application on Zephyr all what is needed is a standard bare-metal GNAT cross
toolchain for the corresponding target and a minimal portable Ada runtime library.
With the proposed approach, the Ada application is built as an Alire library crate,
which is integrated in the zephyr build environment as an external CMake project.
Ada bindings for Zephyr's C APIs are auto-generated from Zephyr header files using
the gcc flag to generate Ada package specifications from C header files.

Keywords: Zephyr, Ada, SPARK.

\end{abstract}

\section{Introduction}

\subsection{What is Zephyr?}

Zephyr \cite{Zephyr1} is an increasingly popular real-time operating system (RTOS) that
supports a wide range of microcontrollers and boards and it is easily extensible to support
custom SoCs and boards.

The Zephyr kernel supports many architectures, including:
\begin{itemize}
\item ARMv6-M, ARMv7-M, and ARMv8-M (Cortex-M)
\item ARMv7-A and ARMv8-A (Cortex-A, 32- and 64-bit)
\item ARMv7-R, ARMv8-R (Cortex-R, 32- and 64-bit)
\item Intel x86 (32- and 64-bit)
\item RISC-V (32- and 64-bit)
\end{itemize}

Zephyr supports a growing number of boards/platforms, which
can be listed with the \verb`west boards` command:

\begin{lstlisting}[language=bash, basicstyle=\ttfamily\scriptsize]
(.venv) $ west boards | wc -l
   959
\end{lstlisting}

\subsection{Why Writing Ada Applications on Zephyr?}
Even if a baremetal GNAT cross-toolchain is available for the corresponding architecture,
the main obstacle for using Ada in many embedded platforms is the shortage of available
ports of the Ada Runtime Library (RTS), even a zero-foot-print RTS.
If we had an Ada Runtime Library for Zephyr, we could get instant support for all the
boards/platforms supported by Zephyr.

The rest of this paper describes a ``light-weight'' approach to write embedded
Ada applications on the Zephyr RTOS environment, using a platform-independent minimal
bare-bones Ada run-time library without tasking support. Instead, auto-generated Ada
bindings for Zephyr's multi-threading C APIs are used. With this approach, an Ada
application is built as an Alire \cite{Alire} library crate, which is integrated in
the zephyr build environment as an external CMake project. The Zephyr application's
C \verb`main()` invokes invokes public subprograms of the Ada application.

\section{Setting up the Development Environment}

\subsection{Zephyr development environment}

The simplest way to set up the Zephyr development environment is to follow the
instructions in the Zephyr Getting Started Guide \cite{Zephyr2}. Then you can create
a subfolder under the \verb`zephyrproject` folder to hold your Ada application project.
In this case the Ada application will be part of the Zephyr west workspace.

Alternatively, to create an ``out-of-tree'' Zephyr application project, you
can create your own west workspace, and make Zephyr a sub-projects of your
west workspace. To do this, follow these steps:

\begin{itemize}
\item Create a folder to hold your own west workspace.
\item Create an `\verb`app` subfolder to hold your Zephyr application project.'''
\item Create file \verb`app/west.yml` with the following content:

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
manifest:
  remotes:
    - name: zephyrproject-rtos
      url-base: https://github.com/zephyrproject-rtos
  projects:
    - name: zephyr
      remote: zephyrproject-rtos
      repo-path: zephyr
      revision: <version, commit or branch>
      import: true # This pulls in other modules
  self:
    path: app
\end{lstlisting}

\item Execute the following commands to set up your west workspace:

\begin{lstlisting}[language=bash, basicstyle=\ttfamily\scriptsize]
$ mkdir <your own west workspace folder>
$ cd  <your own west workspace folder>
$ python3 -m venv .venv
$ . .venv/bin/activate
(.venv) $ pip install west
(.venv) $ west init -l apps
(.venv) $ west update
(.venv) $ pip install -r \
  ./zephyr/scripts/requirements.txt
(.venv) $ cd zephyr
(.venv) $ west sdk install -d \
  <your zephyr sdk folder>
\end{lstlisting}

\end{itemize}

\subsection{Ada development environment}

\begin{itemize}

\item Download and Install the Alire package manager \cite{Alire}.
Alire will automatically download the target GNAT cross toolchain
specified in the \verb`alire.toml` file of the Ada application project.

\item Build a minimal platform-independent Ada runtime library for Zephyr
as an Alire library crate.
The sources of the minimal platform-independent Ada runtime library are copied
from the host GNAT native toolchain. An example of a minimal Ada runtime can be
found in GitHub at \cite{ZephyrAda} in the \verb`apps/zephyr_ada_rts/src/third_party`
folder.

\item  Generate Ada bindings for Zephyr's C APIs using the Zephyr SDK gcc
with the \verb`-fdump-ada-spec` flag. A sample bash script template to auto-generate
Ada bindings for selected Zephyr C header files is shown below.
\begin{lstlisting}[language=bash, basicstyle=\ttfamily\scriptsize]
ZEPHYR_BASE_DIR=<your west workspace dir>/zephyr
ZEPHYR_GCC=<your zephyr sdk toolchain gcc path>
ZEPHYR_CFLAGS=<Zephyr build C flags>
$ZEPHYR_GCC $ZEPHYR_CFLAGS -c -fdump-ada-spec -C \
  ${ZEPHYR_BASE_DIR}/include/zephyr/kernel.h
$ZEPHYR_GCC $ZEPHYR_CFLAGS -c -fdump-ada-spec -C \
  ${ZEPHYR_BASE_DIR}/include/zephyr/posix/pthread.h
\end{lstlisting}

Platform-specific examples of auto-generated Ada bindings for Zephyr's C APIs
can be found in GitHub at \cite{ZephyrAda} in the
\verb`generated_zephyr_ada_bindings` subfolder.
\end{itemize}

\section {Creating a Zephyr Ada ``hello world'' application}

A complete example of a Zephyr Ada ``hello world'' application can be found
at \cite{ZephyrAda}.

\subsection {Zephyr application main skeleton}

\begin{itemize}
\item Create subfolder \verb`zephyr_ada_hello` subfolder under the \verb`app` folder of
your Zephyr west workspace.

\item Add a zephyr application \verb`CMakeLists.txt`' file at \verb`app/zephyr_ada_hello/`,
with the following content:

\begin{lstlisting}[language=make, basicstyle=\ttfamily\scriptsize]
cmake_minimum_required(VERSION 3.20.0)

find_package(Zephyr REQUIRED HINTS
             $ENV{ZEPHYR_BASE})
project(zephyr_ada_hello_world)

target_sources(app PRIVATE src/main.c)
target_link_libraries(app PRIVATE libada_app)
add_subdirectory(ada_app)
\end{lstlisting}

\item Create a \verb`src/main.c` file with the following content:

\begin{lstlisting}[language=C, basicstyle=\ttfamily\scriptsize]
#include "ada_app.h"

int main(void)
{
  // Call gnatbind-generated Ada package elaboration
  // for Ada application library:
  ada_appinit();
  // Call Ada application entry point:
  hello_ada();
  return 0;
}
\end{lstlisting}
\end{itemize}

\subsection {Ada application skeleton}

\begin{itemize}
\item Create an Alire library crate to hold the Ada application code:
\begin{lstlisting}[language=bash, basicstyle=\ttfamily\scriptsize]
(.venv) $ cd app/zephyr_ada_hello
(.venv) $ alr init --lib ada_app
\end{lstlisting}

\item Add dependencies in the \verb`ada_app/alire.toml` file:

\begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
...

[[depends-on]]
zephyr_ada_rts = "*"
gnat_arm_elf = "*"
gprbuild = "*"

[[pins]]
zephyr_ada_rts = { path='../../zephyr_ada_rts' }

[build-profiles]
zephyr_ada_rts = "development"
\end{lstlisting}

\item Create a CMake external project to build the Ada application crate as part of the
Zephyr build:

\begin{lstlisting}[language=make, basicstyle=\ttfamily\scriptsize]
include(ExternalProject)
set(libname libada_app)
ExternalProject_Add(
  ${libname}_external_project
  PREFIX     ${CMAKE_CURRENT_BINARY_DIR}
  SOURCE_DIR ${CMAKE_CURRENT_SOURCE_DIR}
  BINARY_DIR ${CMAKE_CURRENT_BINARY_DIR}
  CONFIGURE_COMMAND ""
  BUILD_ALWAYS 1
  BUILD_COMMAND
    alr --chdir=${CMAKE_CURRENT_SOURCE_DIR} build \
      -- -XBoard=${BOARD}
  INSTALL_COMMAND ""
  BUILD_BYPRODUCTS
    ${CMAKE_CURRENT_SOURCE_DIR}/lib/${BOARD}/${libname}.a
    ${CMAKE_CURRENT_SOURCE_DIR}/../../
        zephyr_ada_rts/lib/${BOARD}/libgnat.a
  )

add_library(${libname} STATIC IMPORTED GLOBAL)
add_dependencies(
  ${libname}
  ${libname}_external_project
  ada_runtime
  )
target_link_libraries( ${libname} INTERFACE ada_runtime )
set_target_properties(${libname}
  PROPERTIES IMPORTED_LOCATION
    ${CMAKE_CURRENT_SOURCE_DIR}/lib/${BOARD}/${libname}.a)
set_target_properties(${libname}
  PROPERTIES INTERFACE_INCLUDE_DIRECTORIES
    ${CMAKE_CURRENT_SOURCE_DIR})
add_library(ada_runtime STATIC IMPORTED GLOBAL)
set_target_properties(ada_runtime
  PROPERTIES IMPORTED_LOCATION
    ${CMAKE_CURRENT_SOURCE_DIR}/../../zephyr_ada_rts/
        lib/${BOARD}/libgnat.a)
\end{lstlisting}

\item Edit the \verb`ada_app/zephyr_ada_hello.gpr` file to specify the
minimal platform-independent Ada runtime library and the Ada application
sources:

\begin{lstlisting}[language=Ada, basicstyle=\ttfamily\scriptsize, escapeinside={`}{`}]
with "config/zephyr_ada_hello_config.gpr";
with "../../compiler_flags.gpr";
with "../../zephyr_ada_rts/zephyr_ada_rts.gpr";

project Zephyr_Ada_Hello is
   for Target use Compiler_Flags.Target_Compiler_Selector;
   for Runtime ("Ada") use Zephyr_Ada_Rts'Runtime ("Ada");
   for Languages use ("Ada");

   for Library_Name use "ada_app";
   for Library_Version use Project'Library_Name & ".a." &
      Zephyr_Ada_Hello_Config.Crate_Version;

`\pagebreak`
   for Source_Dirs use (
      "src/",
      "../../third_party/generated_zephyr_ada_bindings/" &
        Compiler_Flags.Board,
      "config/");
   for Object_Dir use
      "obj/" & Zephyr_Ada_Hello_Config.Build_Profile & "/" &
        Compiler_Flags.Board;
   for Create_Missing_Dirs use "True";
   for Library_Dir use "lib/" & Compiler_Flags.Board;
   for Library_Kind use "static";
   for Library_Standalone use "standard";
   for Library_Interface use ("Zephyr_Ada_Hello");

   package Compiler is
      for Default_Switches ("Ada") use
        Zephyr_Ada_Hello_Config.Ada_Compiler_Switches &
        Compiler_Flags.Compiler.ADAFLAGS;
   end Compiler;
end Zephyr_Ada_Hello;
\end{lstlisting}

\item Create the Ada application top-level package specification as follows:
\begin{lstlisting}[language=Ada, basicstyle=\ttfamily\scriptsize]
with System;
package Zephyr_Ada_Hello is
   procedure Hello_Ada with
      Export,
      Convention => C,
      External_Name => "hello_ada";
private
   procedure Last_Chance_Handler (Msg : System.Address;
                                  Line : Integer)
     with No_Return,
          Export,
          Convention => C,
          External_Name => "__gnat_last_chance_handler";
end Zephyr_Ada_Hello;
\end{lstlisting}

\item Create the Ada application top-level package body. Below
is a partial example that shows how to create a Zephyr thread
from Ada, using the autogenerated Ada bindings for Posix threads
APIs supported by Zephyr. The complete code can be found in the
GitHub repo at \cite{ZephyrAda}:

\begin{lstlisting}[language=Ada, basicstyle=\ttfamily\scriptsize]
with Interfaces.C;
with GNAT.Source_Info;
with zephyr_posix_pthread_h;
with zephyr_posix_sched_h;
with zephyr_posix_posix_types_h;
with sys_utimespec_h;
with time_h;

package body Zephyr_Ada_Hello is
   use Interfaces;
   use type C.int;
   use type C.long;
   use type System.Address;
   package pthread_h renames
    zephyr_posix_pthread_h;
   package sched_h renames zephyr_posix_sched_h;
   package posix_types_h renames
    zephyr_posix_posix_types_h;
   package timespec_h renames sys_utimespec_h;
   ...

   function Service1_Thread_Func (arg : System.Address)
      return System.Address
      with Convention => C;
   ...

   procedure Hello_Ada is
      C_Ret : C.int;
      Max_Posix_Priority : constant C.int := 31;
      Sched_Param : aliased sched_h.sched_param;
      Thread_Handle : aliased posix_types_h.pthread_t;
   begin
      Printk (
        "Hello Ada (built on " &
        GNAT.Source_Info.Compilation_Date & " at " &
        GNAT.Source_Info.Compilation_Time & ")" &
        ASCII.LF);

      C_Ret := pthread_h.pthread_create (
        newthread => Thread_Handle'Access,
        attr => null,
        threadroutine => Service1_Thread_Func'Access,
        arg => System.Null_Address);
      pragma Assert (C_Ret = 0);
      Sched_Param.sched_priority :=
        Max_Posix_Priority - 1;
      C_Ret := pthread_h.pthread_setschedparam (
        Thread_Handle, sched_h.SCHED_RR,
        Sched_Param'Access);
      pragma Assert (C_Ret = 0);
      ...
   end Hello_Ada;
   ...
   function Service1_Thread_Func (arg : System.Address)
      return System.Address
   is
      Cnt : C.int := 0;
      Current_Time : aliased timespec_h.timespec;
      Next_Wakeup_Time : aliased timespec_h.timespec;
      Remaining_Sleep_Time :
        aliased timespec_h.timespec;
      C_Ret : C.int;
   begin
      pragma Assert (arg = System.Null_Address);
      C_Ret := time_h.clock_gettime (
                  clock_id => time_h.CLOCK_MONOTONIC,
                  tp => Current_Time'Access);
      pragma Assert (C_Ret = 0);

      Next_Wakeup_Time := Current_Time;
      loop
         Cnt := Cnt + 1;
         Printk (
            "Ada thread1: counter %u @ %llus, %lums, %luns" &
              ASCII.LF,
            C.unsigned (Cnt),
            C.unsigned_long_long (Current_Time.tv_sec),
            C.unsigned_long (Current_Time.tv_nsec /
                             Nsec_Per_Msec),
            C.unsigned_long (Current_Time.tv_nsec mod
                             Nsec_Per_Msec));

         Next_Wakeup_Time := Calc_Next_Wakeup_Time (
            Next_Wakeup_Time,
            Service1_Period_Ms);
         ...
         C_Ret := time_h.clock_nanosleep (
            clock_id => time_h.CLOCK_MONOTONIC,
            flags => time_h.TIMER_ABSTIME,
            rqtp => Next_Wakeup_Time'Access,
            rmtp => Remaining_Sleep_Time'Access);
         pragma Assert (C_Ret = 0);
         ...
      end loop;
   end Service1_Thread_Func;
\end{lstlisting}
\end{itemize}
